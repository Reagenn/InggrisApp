Cara memakai

  1. Buka tab Kosakata, cari kata, dengarkan, lalu pencet Tandai Hapal kalau sudah hafal.
  2. Uji dirimu di tab Kuis Kata dan Grammar (kuisnya dipisah per topik grammar).
  3. Latih ucapan di tab Speaking dan baca cerita di tab Cerita.
  4. Progress tersimpan otomatis di komputer ini (file backend/data/data.json). Hapus file itu untuk mengulang dari nol.
